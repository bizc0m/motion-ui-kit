# Motion UI Kit

Kit UI maison — pas de framework, pas de build tool, pas de dépendance.

- **38 composants** HTML/CSS/JS
- **30 sections** de landing page
- **15 effets** d’animation et transition
- **6 presets de menu**
- **3 piliers** : UX, Menu, Effects

## Stack

HTML5 · CSS3 (custom properties, flexbox, grid, animations) · JavaScript vanilla.

## Démarrer

Ouvrir `index.html` dans un navigateur, ou servir localement :

```bash
python3 -m http.server 8000
```

Puis : http://localhost:8000

## Structure

```
.
├── index.html       # page de démo complète
├── styles.css       # tokens + 38 composants + 30 sections + effets + menus
├── main.js          # rendu dynamique et interactions
└── README.md
```

## Fichiers source

Tout est écrit à la main dans `index.html`, `styles.css` et `main.js`. Aucun code généré par un template d’outil de build.
